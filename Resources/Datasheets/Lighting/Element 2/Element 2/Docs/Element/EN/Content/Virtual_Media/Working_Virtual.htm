Working with the Virtual Media Server

Before you begin working with the Virtual Media Server, you will want to open the Pixel Map Preview display from the home screen or by using [Tab] [1][0]. For manipulating the pixel maps, you can use the ML Controls, which can be opened from the home screen, by using [Tab] [5], or by using the quick access tools.

Note: For any output, the Server Channel must be set to a level along with any layers you are using.

Note: You can use Park and Address Check for Virtual Media Server outputs.
