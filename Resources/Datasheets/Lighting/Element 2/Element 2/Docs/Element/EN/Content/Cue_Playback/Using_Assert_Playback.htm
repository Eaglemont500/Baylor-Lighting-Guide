Using Assert (Playback Button)

Use [Live] {Fader Control} {Assert} & [Load] for the master fader pair to re-run the active cue in that fader, following the same rules as [Go To Cue]. Assert can be used to regain control of all cue contents, or make any changes in Blind to an active cue on stage.

When [Live] {Fader Control} {Assert} & [Load] are used together, the entire contents of the cue are replayed.
