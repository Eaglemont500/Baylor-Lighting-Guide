Key

OSC Method

Arguments

Examples/Comments

/eos/key/<name>

number for button edge: 1.0=down, 0.0=up (optional)

/eos/key/select active=1.0 (press [Select Active] but- ton)

 

/eos/key/select active=0.0 (release [Select Active] but- ton)

 

/eos/key/go 0

(press & release [Go] button)

Note: For the slash key, use a backslash /eos/key/\
