Range Patching

Range patching using the [Thru] key allows you to quickly patch a group of channels. [1][Thru][2][0] [At] [1] [0] [Enter] patches channels 1 through 20 to addresses 10 through 29.

You can also use the [+] and [-] keys. [1] [+] [4] [+] [8] [At] [1] [Enter] patches channel 1 to address 1, channel 4 to 2, and channel 8 to 3. The [Group] key can also be used if groups have been created.

Note: Range patching only works with channels. If you try to range patch addresses, parts for the channel will be created. See Creating multipart and compound channels .

Note: If you try to patch a channel or address that exceeds the console's capacity, an error message saying number out of range will display on the command line.
