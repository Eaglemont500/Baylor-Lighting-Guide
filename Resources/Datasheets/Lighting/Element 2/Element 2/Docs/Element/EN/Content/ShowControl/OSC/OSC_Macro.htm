Macro

Selects and fires (executes) macros

OSC Method

Arguments

Examples/Comments

/eos/macro

number for macro to select

/eos/macro=1

/eos/macro/fire

number for macro to run

/eos/macro/fire=1

/eos/macro/<number>/fire

number for button edge: 1.0=down, 0.0=up (optional)

/eos/macro/1/fire=1.0
