Basic Cueing

In Setup, you determine if Element will operate in a Cue Only or Tracking mode. See Tracking vs. Cue Only By default, the system is set to tracking, therefore this section primarily addresses working in tracking mode. The current mode is displayed in the upper left corner of the live/blind display. It is important to know which mode you are working in, as it impacts how cues are edited.

Note: The current mode of the console will be displayed in the upper left corner of the Live or Blind tab. The command line prompts will also provide some guidance depending on the current mode.

  • If your console is set in Track mode (default), changes move forward through the cue list until a block or a move instruction is encountered.
  • If your console is set in Cue Only mode, changes to cues have no impact on subsequent cue data.
