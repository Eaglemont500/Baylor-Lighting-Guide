Element Hotkeys

To enable Element functions on Mac Function keys:

  • Open Systems Preferences
  • Go into the Keyboard section
  • Enable the “Use all F1, F2,etc... keys as standard function keys” setting.

Note: Some international keyboards require “Use Shift Key as Eos Shift” to be disabled in the General section of the ECU Settings. Use Z as shift to access shortcut functions in these cases.
