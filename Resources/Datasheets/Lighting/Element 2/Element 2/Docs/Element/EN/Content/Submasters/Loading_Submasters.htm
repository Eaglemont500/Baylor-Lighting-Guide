Loading Submasters

Submasters can also be loaded with presets, or palettes. You can convert an empty fader to a submaster without configuring it in fader configuration display. Any fader can be configured and loaded with a submaster if:

  • the fader is not configured

-or-

  • the fader is configured as a submaster, but that submaster is empty.

Regardless of the fader configuration, if the above conditions are met, the fader can be loaded with the submaster or target specified on the command line.

If data already occupies the fader, that fader must be unloaded before another target can be loaded. See Releasing Content From a Submaster

  • [Sub] [5] [Load] - loads submaster 5 to the fader associated with the load button.
  • [Int Palette] [1] [Load] - loads intensity palette 1 to the submaster associated with the chosen load button.
