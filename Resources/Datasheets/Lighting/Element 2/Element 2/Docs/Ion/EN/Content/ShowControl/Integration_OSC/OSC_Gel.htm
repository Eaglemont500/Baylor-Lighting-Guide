OSC Gel

Gels will be represented as strings in the following format:

<Gel Manufacturer Abbreviation><Gel Number>

For Example: 

“AP1150”

(Apollo 1150)

“G101” 

(Gam 101)

“L2”

(Lee 2)

“R80” 

(Rosco 80)

“SG1” 

(Rosco Super Gel 1)

“E194” 

(Rosco E Color 194)

“T12”

(TokyoBS Poly Color 12)
