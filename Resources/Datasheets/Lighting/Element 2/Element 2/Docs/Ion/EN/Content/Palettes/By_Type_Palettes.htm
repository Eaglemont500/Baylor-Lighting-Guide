{By Type}

By Type palettes are created with 'default' channels which contain values that can be assigned to any other channel within the same fixture type. By Type palettes can also contain discrete channel values.

By Type palettes will display a ‘T’ in the lower corner of the direct selects and in the palette lists. A ‘+’ will display after the ‘T’ if there are channels stored with discrete data. For more information on by type palettes, see Using By Type Palettes .
