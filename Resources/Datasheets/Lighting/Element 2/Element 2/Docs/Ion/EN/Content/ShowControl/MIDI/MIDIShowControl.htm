MIDI Show Control

Eos Family consoles can receive MIDI Show Control (MSC) data from Net3 Show Control Gateways and the built-in MIDI ports on a console or programming wing (when available). There can be up to 32 sources, and these sources can be assigned Group IDs between 1 and 32. MIDI Show Control is one of many different types of MIDI signals – MIDI Time Code and MIDI Notes are supported, but described elsewhere in this document. All other incoming MIDI is ignored.

Eos Family consoles can also transmit MIDI Show Control data.
