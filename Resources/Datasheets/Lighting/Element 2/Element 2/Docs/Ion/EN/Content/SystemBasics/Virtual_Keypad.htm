Virtual Keyboard

It is possible to open a keyboard which mimics the hard keys found on the actual Ion keypad.

To open, you can select the virtual keyboard from the Home Screen or use [Tab] [7].

The virtual keyboard displays the alphanumeric keyboard shortcut for that hardkey in the lower right hard corner.

The abbreviations are:

  • Ca - CTRL + ALT
  • S - SHIFT
  • C - CTRL
  • A - ALT
