Scroller Fan Curves

Curves can be applied to the scroller fan parameter allowing for the output of the fan to be controlled by the intensity of the channel. The curves available for this are the same used for intensity parameters and cues. See Applying a Curve To Scroller Fans .

To set a curve to a scroller fan, go to Displays>Patch>Attributes>Fan Curve for each scroller.
