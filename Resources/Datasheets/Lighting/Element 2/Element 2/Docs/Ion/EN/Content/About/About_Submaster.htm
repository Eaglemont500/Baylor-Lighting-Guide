[About] Submaster

The following information will be displayed when a submaster is selected:

  • The submaster number
  • Label (if any)
  • Current value
  • Mode (additive, inhibitive, or effectsub)
  • Fader (proportional or intensity master)
  • HTP or LTP
  • Exclusive
  • Priority
  • Timing
  • Fader Pages
  • Channels in Submaster
  • Effects assigned
