Using The Cue List Index

The cue list index is a blind display list which shows the cue list you are working with, the cue status, cue list properties, any other stored cue lists, and what (if any) faders the lists are loaded onto.

When the cue list index is in focus, the following softkeys are available for editing the cue list: {Partition}, {Autoblock Clean}, {Solo Mode}, {Execute} ,{Properties}, and {Edit}.
