Switch

Note: Switch is a variant of Wheel with the added functionality of continuously repeating wheel ticks until a subsequent OSC switch command sets the wheel ticks to zero.
This may be used to continuously tick a wheel while a button is held down, for example. The expected argument range is -1.0 to 1.0, which affects the tick rate accordingly, but can be a smaller or larger range for more subtle or rapid movement.
