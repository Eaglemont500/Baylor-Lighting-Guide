Welcome

Welcome to the Eos Titanium (Ti), Eos, Gio, Gio @ 5, Ion Xe, and Element 2 Operations Manual. This manual is a comprehensive resource for users of the Eos Ti, Eos, Gio, Gio @ 5, Ion Xe, and Element 2 control systems.

Using the Online Operations Manual

The online Operations Manual is split into two sections, the left side which displays the Table of Contents and Index for the 2.8.0 Operations Manual, and the right side which displays the content of the selection.

If you are viewing the online Operations Manual on a smaller display, the Table of Contents, Index, and Search can be opened by clicking on the hamburger icon () at the top of the window.

Tools

The Search field () is displayed on the top right corner of the page. Enter one or more keywords in the field and click the search button or press enter. Links to topics containing the search keyword(s) are listed in the content section of the page. Clicking on a topic link displays the associated topic page.

Use the button to expand or collapse all drop down text on the page.

Use the buttons to navigate to the next or previous topic in the system.
