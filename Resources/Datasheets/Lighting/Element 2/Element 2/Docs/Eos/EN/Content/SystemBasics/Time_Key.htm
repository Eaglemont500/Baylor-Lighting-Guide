[Time] Key

Pressing and holding [ [About] & [Time]] allows you to view discrete timing data behind any channel parameter. [Time] exposes channel or parameter specific timing for any channels in the current cue. The first value is the delay time. If “--” is displayed, there is no delay. The value to the right of the / is the transition time.

You can lock this mode by pressing [About] & [Time]. When in display time mode, “Display Timing” will display in the upper left of the live display. To exit this mode, press [About] again.
