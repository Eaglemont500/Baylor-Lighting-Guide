[Go To Cue 0]

Note: On Eos, the button is [GoTo Q0] .

You can use the [Go To Cue 0] button, located with the playback controls, in conjunction with a fader load button, to send a specific cue list to cue 0. This action does not use the command line. Simply press:

  • [Go To Cue 0] & [Load] for the desired fader

On Element 2, you can use the [Go To Cue] [0] [Enter] command to send the cue list to cue 0. This drives all cue intensities to zero, while leaving non-intensity parameters as currently set but no longer under cue control.

For more information on this action, see Using Go To Cue 0
