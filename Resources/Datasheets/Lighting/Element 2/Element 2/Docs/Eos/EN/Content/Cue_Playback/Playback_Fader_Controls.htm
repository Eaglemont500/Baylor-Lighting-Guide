Playback Fader Controls

The following buttons are found in the Master Fader controls or in the Fader Page controls area of your console. See Playback Controls

The following controls are available:

  • Load (Selected Cue )
  • Go (Using [Go] )
  • Stop/ Back (Using [Stop/ Back] )
  • Blackout (Using Blackout and Grandmaster )
  • Grandmaster (Using Blackout and Grandmaster )
  • Go To Cue 0 ([Go To Cue 0] )
  • Assert (Using Assert (Playback Button) )
  • Timing Disable (Using Timing Disable
  • Freeze Using Freeze )
  • Stop Effect (Using Stop Effect )
  • Rate Override (Using Rate Override )
  • Manual Override (Manual Override )
  • Off (Releasing Content From a Fader )
  • Release (Releasing Content From a Fader )
  • Fader Page (Changing Fader Pages )
