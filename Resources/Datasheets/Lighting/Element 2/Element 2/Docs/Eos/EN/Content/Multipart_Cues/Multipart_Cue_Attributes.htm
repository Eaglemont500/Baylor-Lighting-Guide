Setting Multipart Attributes and Flags

Cue attributes include Follow, Hang, Link, Loop, Delay Time, Rate, Curve, Cue Notes, Cue Labels, and Scenes. They are stored and function exactly as they do in single part cues.

Flags can be set for Block, Assert, AllFade, Mark, and Preheat. Assert and AllFade are not available on Element 2.

For more information, see Assigning Cue Attributes and Flags .

Cue part attributes can be defined as the parts are recorded, or they can be added after the part has been created.

For Example: 

  • [Record] [Cue] [2] [Part] [1] [Delay] [8] [Enter]
  • [Cue] [4] [Part] [3] {Color} [Time] [6] [Enter]
  • [Cue] [8] [Part] [9] {AutoMark Off} [Enter]
  • [Record Only] [Cue] [5] [Part] [2] [Assert] [Enter]
